# E05 Calidad de análisis de suelo

Sesión 4. Trabajo activo orientativo: 135 minutos, integrado con demostración y discusión según la agenda.

## Propósito

Construir un flujo auditable que conserve los datos que requieren revisión y calcule poblaciones analíticas explícitas.

## Datos y descarga

D01 AGROSAVIA: agrosavia.csv, 20.380 MB, completo.

D02 DIVIPOLA: divipola.csv, 0.071 MB, completo.

Con el kit completo ejecutar --verificar. Para obtener una nueva copia utilizar la ruta B del capítulo de descarga y los IDs indicados abajo. Los shapes DANE se descargan por navegador. Todas las URLs están en el catálogo y en fuentes.json.

```
python 00_datos.py --descargar agrosavia divipola
```

## Instrucciones

1. Leer las 32 columnas originales como texto. Definir duplicado exacto como igualdad en todas ellas, incluido Secuencial.
2. Transformar pH con conversión tolerante; marcar ausencias, valores fuera de 0–14 y conflictos de identificador. Conservar ph_texto y fila_fuente.
3. Interpretar Fecha de Análisis como día/mes/año. Normalizar acentos y espacios de departamento y municipio para un enlace exacto controlado con DIVIPOLA.
4. Ejecutar calidad y comparar controles.json con controles_referencia.json. Revisar las 11 filas sin pH numérico y los territorios no encontrados.
5. Verificar raw = duplicados exactos + aptos para pH + revisión de pH. Reportar la cobertura territorial como dimensión independiente.

## Ejecución

```
python talleres.py calidad
```

## Entrega y criterios

Para este corte: 92.738 originales = 0 duplicados exactos + 92.727 aptos para pH + 11 en revisión. 2.138 registros requieren revisar correspondencia territorial. Entregar reporte, reglas y dos ejemplos comentados.

## Advertencia de interpretación

“Apto para pH” no significa “suelo de buena calidad” ni registro válido para toda pregunta. No descartar toda una fila porque falte otra propiedad. No corregir municipios por similitud sin revisar.
