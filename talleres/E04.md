# E04 Formatos y contrato de datos

Sesión 3. Trabajo activo orientativo: 60 minutos, integrado con demostración y discusión según la agenda.

## Propósito

Seleccionar formatos según el uso y documentar el contrato antes de depurar.

## Datos y descarga

D01 AGROSAVIA: agrosavia.csv, 20.380 MB, completo.

D06 Correlación de suelos IGAC: igac_correlacion.json, 0.012 MB, muestra.

D11 NASA POWER: nasa.json, 0.002 MB, muestra.

Con el kit completo ejecutar --verificar. Para obtener una nueva copia utilizar la ruta B del capítulo de descarga y los IDs indicados abajo. Los shapes DANE se descargan por navegador. Todas las URLs están en el catálogo y en fuentes.json.

```
python 00_datos.py --descargar agrosavia igac_correlacion nasa
```

## Instrucciones

1. Comparar el CSV de AGROSAVIA, el JSON de NASA y los atributos IGAC. Identificar encabezados, jerarquías y tipos aparentes.
2. Definir el contrato de pH: conservar texto original, separar conversión numérica, rango físico y disponibilidad territorial.
3. Decidir qué conservar en raw, qué derivar en Parquet y qué resumir en una tabla analítica.
4. Ejecutar la etapa de calidad como demostración y comprobar que su salida Parquet puede leerse sin inferir encabezados ni separadores. El taller E05 explicará cada regla.
5. Documentar particiones potenciales por año y por qué no crear miles de archivos por municipio en un conjunto pequeño.

## Ejecución

```
python talleres.py calidad
```

## Entrega y criterios

Entregar un contrato con campo, tipo, ausencia, regla, tratamiento y procedencia. La decisión de arquitectura debe explicar CSV para intercambio, JSON para API y Parquet para análisis.

## Advertencia de interpretación

Comprimir o particionar no corrige errores semánticos. Parquet no convierte una carpeta en lakehouse ni aporta por sí solo transacciones.
