## Propósito

Distinguir clases cartográficas, mediciones por horizonte y predicciones ráster, evitando comparaciones sin soporte espacial.

## Datos y descarga

D09 SoilGrids pH: soilgrids.tif, 0.002 MB, muestra.

D10 WoSIS Colombia: wosis.json, 0.007 MB, muestra.

D08 Propiedades químicas IGAC: igac_quimica.json, 0.030 MB, muestra.

D06 Correlación de suelos IGAC: igac_correlacion.json, 0.012 MB, muestra.

Con el kit completo ejecutar --verificar. Para obtener una nueva copia utilizar la ruta B del capítulo de descarga y los IDs indicados abajo. Los shapes DANE se descargan por navegador. Todas las URLs están en el catálogo y en fuentes.json.

```
python 00_datos.py --descargar soilgrids wosis igac_quimica igac_correlacion
```

## Instrucciones

1. Ejecutar clima para obtener el inventario de ráster y perfiles. Consultar método, profundidad y licencia de WoSIS.
2. Contar diez registros y tres perfiles distintos; construir una tabla por profile_id y profundidad.
3. En QGIS abrir soilgrids.tif y comprobar 44 × 42 celdas. Aplicar el factor pH = valor/10.
4. Detectar 188 celdas cero sin NoData declarado. El script las excluye provisionalmente de la media interpretativa y las reporta como pendientes; no sustituye ni edita el original.
5. Comparar los intervalos del mapa químico IGAC y la taxonomía de correlación. Explicar por qué no se calcula un error de predicción con perfiles fuera del recorte o sin igual profundidad.

## Ejecución

```
python talleres.py clima
```

## Entrega y criterios

Reporte de unidades, método y profundidad; 1.660 celdas con pH positivo dentro del dominio tras separar los 188 ceros. Entregar un mapa con alcance y una lista de condiciones para validar predicciones.

## Advertencia de interpretación

SoilGrids es una predicción y AGROSAVIA/WoSIS contienen mediciones con métodos y muestreo propios. No presentar clases o píxeles como análisis de una finca. No hay un índice integral de salud del suelo validado en este ejercicio.

## Ampliación dentro del bloque

Diseñar, sin inventar mediciones, un protocolo para evaluar SoilGrids con puntos coincidentes y profundidad compatible.
