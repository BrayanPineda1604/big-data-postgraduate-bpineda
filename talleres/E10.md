# E10 Rendimiento del procesamiento

Sesión 7. Trabajo activo orientativo: 135 minutos, integrado con demostración y discusión según la agenda.

## Propósito

Medir tiempo y tamaño de archivos preservando una consulta equivalente.

## Datos y descarga

D05 EVA UPRA 2019 a 2025: eva.csv, 27.490 MB, completo.

Con el kit completo ejecutar --verificar. Para obtener una nueva copia utilizar la ruta B del capítulo de descarga y los IDs indicados abajo. Los shapes DANE se descargan por navegador. Todas las URLs están en el catálogo y en fuentes.json.

```
python 00_datos.py --descargar eva
```

## Instrucciones

1. Ejecutar benchmark después de consultas. Usar la tabla normalizada exportada a CSV y Parquet, de modo que ambas tengan las mismas filas y columnas.
2. Registrar máquina, RAM, motor, versión, hilos y archivos. El script utiliza dos hilos, una ejecución de calentamiento y cinco repeticiones.
3. Comparar conteo y suma entre formatos antes de interpretar tiempos. La suma global solo es un control computacional; no es un indicador agronómico agregado recomendado.
4. Calcular mediana de tiempos y razón de tamaños. Discutir caché de sistema operativo e inferencia de esquema CSV.
5. Ejecutar una consulta alternativa con proyección de pocas columnas y explicar qué podría aprovechar Parquet.

## Ejecución

```
python talleres.py benchmark
```

## Entrega y criterios

benchmark.csv debe contener dos filas con igual población: 159.616 registros aptos para rendimiento. Las medianas de tiempo se miden en cada equipo y no tienen un valor esperado obligatorio.

## Advertencia de interpretación

No multiplicar ni replicar observaciones para declarar mayor cobertura. No prometer que Parquet o Spark siempre será más rápido. Este experimento mide una consulta y configuración concretas.
